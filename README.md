# Daraz-Order-Prediction-Project

A Streamlit app that predicts daily orders using Linear Regression based on website visitors, ad spend, discount percentage, and day type.

## Features
- Predict daily orders using interactive inputs.
- View model performance with MAE and R².
- Explore the dataset, charts, and model coefficients.

## Built With
Python, Streamlit, Pandas, and Scikit-learn.

## Run
Keep `daraz_daily_orders_synthetic(1).csv` beside `app.py`.

```bash
pip install streamlit pandas scikit-learn
streamlit run app.py
```

This project uses synthetic data for learning purposes.
